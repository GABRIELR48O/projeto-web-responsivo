# 🎲 Sorteador de Números

Um aplicativo web moderno, responsivo e interativo para sorteio de números, desenvolvido com HTML5, CSS3 e JavaScript puro. O projeto conta com suporte a intervalos personalizados, opção de exclusão de números repetidos, efeitos visuais de gamificação e adaptação perfeita para telas de computadores e dispositivos móveis.

## 🚀 Funcionalidades

* **Sorteio Personalizado:** Defina a quantidade de números, além dos valores de intervalo mínimo e máximo.
* **Opção de Repetição:** Escolha se os números sorteados podem ou não se repetir.
* **Validação Inteligente:** Tratamento de erros e avisos caso os campos fiquem vazios ou o intervalo seja inválido.
* **Animação e Gamificação:** Exibição dinâmica dos resultados em formato de bolinhas com animação de atraso e chuva de confetes ao finalizar o sorteio.
* **Totalmente Responsivo:** Layout flexível otimizado para celulares, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação semântica)
* **CSS3** (Flexbox, Variáveis, Estilização moderna e Media Queries)
* **JavaScript (ES6+)** (Lógica de sorteio, manipulação de DOM e tratamento de eventos)
* **Canvas Confetti** (Biblioteca externa via CDN para efeitos visuais de premiação)
